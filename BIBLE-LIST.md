## B. Copyrighted — need a licensed source, NOT the GitHub repos

You asked for NIV, ESV, TPT and AMP. These are strictly copyrighted. The GitHub
repos carry them with **no licence**, so pulling them from there would mean the
church redistributing them illegally. The legitimate routes:

| Bible | Legitimate source |
|---|---|
| NIV | API.Bible (Biblica) — depends on what your key is approved for |
| ESV | Crossway's own free non-commercial API (separate key, api.esv.org) |
| AMP | Lockman Foundation — licence request |
| TPT | Passion & Fire Ministries — licence request |
